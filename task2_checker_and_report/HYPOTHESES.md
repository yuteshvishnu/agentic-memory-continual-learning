# Hypotheses (CS 839 HW1)

**H1 – memory helps.** On the rule-reuse tasks (T2–T4, T7, T10), structured memory reaches
>= 80% first-attempt success and uses fewer attempts on average, while no memory stays <= 30%,
because no memory must rediscover C1 and C2 on every task.

**H2 – memory hurts or does nothing.** On T5, both memory conditions have lower first-attempt
success than no memory, because they over-apply the 08:00 observation-day shift to Wingra.
On T6, episodic memory does worse than structured if a retrieved trace shows whole rows being
dropped. On T1, all three conditions perform the same, since nothing has been learned yet.

Both are falsifiable from first-attempt-success per task per condition (3 repeats each).
